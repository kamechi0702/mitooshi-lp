## 1. 継承するコンセプト（変わらない骨格）

### Why
軽度ASD/ADHDの子どもは「次に何をするか」が言葉だけでは伝わりづらく、切り替えに失敗しやすい。一方、**視覚的に順番が見えれば自走できる**力を持っている。mitooshi は、親が事前に「今日やることリスト」を組んでおき、子どもが自分で上から順にタップで消化していく見通しボードアプリ。

### ペルソナ
- **保護者**：30〜40代、共働き多数。声かけに疲弊、絵カードが続かなかった経験あり
- **子ども**：3歳〜小学校低学年、軽度ASD/ADHDの特性、視覚情報に反応する

### プロダクト原則（v3 版）
1. **2タップで取り出せる** — TOPからリスト実行までを最大2タップ
2. **子どもが主役** — 子ども自身がタップしてタスクを消す
3. **見て分かる** — 絵・写真・時計でひと目で行動が分かる
4. **親の事前編集 × 子どもの実行** を明確に分離する（2モード原則）
5. **絵文字を使わない** — イラスト・写真・時計で表現

## 3. ナビゲーション構造（Apple HIG 準拠タブバー）

```
┌────────────────────────────┐
│                            │
│       （画面コンテンツ）      │
│                            │
├────────────────────────────┤
│  🏠 TOP   ➕ 新規作成  👤 マイページ │
└────────────────────────────┘
```

- 画面下部に固定のタブバー（3項目）
- 中央の「新規作成」は**FAB風に強調**（ミントの円形背景、大きめサイズ）
- 画面右上の歯車は**撤去**（設定は「マイページ」タブへ統合）
- タブバーは TOP／作成フロー（S2〜S5）／マイページの遷移時に常時表示、S6 実行画面とS7完了画面では**非表示**（子ども画面の集中阻害を防ぐ）

## 4. カードの4タイプ

| タイプ | 構成要素 | 例 |
|---|---|---|
| **A. イラスト + 単語** | プリセットイラスト(`shared/illust/mitooshi/*.png`)+ ひらがなラベル | はをみがく（歯磨きの絵）|
| **B. 写真 + キャプション** | 親が撮影 or アップした写真 + 16文字以内キャプション | うちのかばん（実写）|
| **C. 時計 + キャプション** | アナログ時計 + 時:分 + キャプション | 8:00 ランドセルもっしゅっぱつ |
| **D. 文字のみ** | ひらがなテキストのみ | ガソリンスタンドいく |

### カードの表示ルール
- **TOP・実行画面・編集画面のリスト表示時**：横並び「画像/アイコン＋テキスト」形式（画像と文字は分離）
- **作成画面の確認ステップでのみ**：画像内に文字を埋め込んだ統合カードを表示（親が「このカードはこういう行動」と確認するため）
- **文字のみタイプ（D）**：画像エリアは空欄 or 小さな「📝」風アイコン代わり

## 5. 体験フロー

### F1. リスト実行（日常の最頻出フロー）
```
TOP → リストをタップ → S6 実行画面 → 上から順にタップで消化 → 最後の1枚を消すと S7 完了 → ホームへ戻る
```
**所要操作**：2タップ（リスト選択＋最初のタスク消化）。

### F2. リスト新規作成
```
下部タブ「+ 新規作成」タップ → S2 タイトル入力 → 「保存してタスクを作る」
→ S5 リスト編集画面（空） → ＋ボタン → S3 カード種別選択
→ 種別別作成（S4a/b/c/d） → 確認（S4末尾） → S5 に追加
→ 必要回数くり返し → 「リストを保存する」 → TOP
```

### F3. リスト編集
```
TOP のリストを**長押し**（または長押しで現れる鉛筆アイコンをタップ）
→ S5 リスト編集画面 → 並び替え／カード削除／カード編集／＋追加
→ 「リストを保存する」 → TOP
```

### F4. お気に入り切替
```
TOP のリスト行、右端の☆（薄グレー）をタップ → ★（黄色）に切替、お気に入りセクションへ自動移動
```

## 6. 機能要件（FR）

### FR-001 TOP（リスト一覧）
- **お気に入りセクション**：☆→★でマークしたリストを上位に表示、タイトル右側に黄色★
- **通常リスト**：上記以外のリスト、薄グレー☆表示
- 両セクションは区切り線で分離
- 各行に「›」の遷移インジケータ、タップで実行画面へ
- リスト行の**長押しで編集モード**起動
- 空状態：プリセット3リスト（あさのしたく／おでかけ／おやすみ）が自動的に入っている

### FR-002 下部ナビゲーションバー
- 固定・常時表示（S6/S7 は非表示）
- 左：**🏠 TOP**（ホーム）
- 中央：**➕ 新規作成**（FAB風・ミント強調）
- 右：**👤 マイページ**（設定）
- アクティブタブは色強調（ミント）

### FR-003 リスト新規作成（S2）
- ヘッダー：← 戻る／ タイトル「リストを新規作成する」／ 右上歯車は**なし**
- 中央：「リストのタイトル（20文字まで）」入力フィールド＋プレースホルダ「例）朝のお支度」
- 下部固定：ミントの「保存してタスクを作る ›」CTA
- タイトル空では CTA 無効

### FR-004 カード種別選択（S3）
- ヘッダー：← 戻る／タイトル「リスト名が入ります」
- 4つの選択肢を縦に並べたボタン：
  1. **イラストからえらぶ** ›
  2. **スマホから画像をアップしてつくる** ›
  3. **時計をえらぶ** ›
  4. **文字を入力する** ›
- 各ボタンに小さなサンプルアイコン

### FR-005 カード作成（S4a：イラスト）
- プリセットカードのグリッド表示（`shared/illust/mitooshi/*.png` の32枚＋今後追加分）
- カード種別カテゴリのセクション分け：「幼児一日」「家庭カレンダー」「食べ物」「物」等のタグ
- タップで選択 → S4末尾（テキスト確認）へ

### FR-006 カード作成（S4b：画像アップロード）
- 「写真・画像を選択」ボタン（写真ライブラリ／カメラ／ファイル選択のアクションシート）
- アップロード後、プレビュー＋「キャプションを入力（16字まで）」
- 「保存する」で S5 に追加

### FR-007 カード作成（S4c：時計）
- 時・分を選ぶドロップダウン（時：0-23、分：0-59）
- アナログ時計がリアルタイムにプレビュー
- 「キャプションを入力（16字まで）」
- 「保存する」で S5 に追加

### FR-008 カード作成（S4d：文字）
- ひらがな／カタカナ／漢字混在可のテキスト入力（16字まで）
- 画像エリアは空欄（絵なし）
- 「保存する」で S5 に追加

### FR-009 カード確認ステップ（S4共通末尾）
- 「テキストを変更したい場合は変更してください」のラベル
- **作成画面のときだけ**：絵＋文字を統合カード表示（親が「こういう行動」と確認）
- 保存ボタンで S5 へ

### FR-010 リスト編集・プレビュー（S5）
- 追加済みカードをリスト形式で表示（左：画像/アイコン、右：テキスト）
- 各行の左に**赤いゴミ箱**アイコン（タップで削除確認→削除）
- 各行の右に**鉛筆**（タップで該当カードの作成画面に戻る）と**ハンバーガー**（ドラッグで並び替え）
- 下部左：**＋**ボタン（S3へ、カード追加）
- 下部右：ミントの「リストを保存する ›」CTA

### FR-011 実行画面（S6）
- ヘッダー：長押しで戻る（「ながおし」ヒント付き）／リスト名／進捗（例 3/5）
- **リスト形式**でタスクを縦に表示
- 各行：チェックボックス風の円＋画像/アイコン＋テキスト
- **タップするとその行がふわっと消えるアニメーション**（透明度＋上方向フェード、350ms）
- 消化した行は画面から消える
- 全行消化すると S7 完了画面へ自動遷移
- タイマーなし
- 実行中の編集・追加なし

### FR-012 完了画面（S7）
- 達成アイコン（ミントの大きなチェック）＋紙吹雪
- 「ぜんぶ できたね！」メッセージ
- リスト名表示
- 「ホームに もどる」ボタン
- **タブバー非表示**

### FR-013 マイページ（S8）
- 旧「設定画面」＋ユーザープロファイル的要素
- 内容：子どもの名前設定／効果音／プラン状態／プライバシー／利用規約／問い合わせ
- 将来的に：使用統計・家族設定・カード生成依頼 等も

### FR-014 お気に入り管理
- TOP のリスト行の右側に☆アイコン
- 未設定：薄グレー☆
- 設定済み：ミント or 黄色★
- タップで切替、切替と同時にお気に入りセクションへ自動移動（小さくアニメ）

### FR-015 オフライン動作
- TOP／作成／編集／実行／完了の主要動作はネットワーク不要
- イラストは事前バンドル、写真はローカル保存

## 8. データモデル

### Card（基底）
```ts
type CardType = 'illust' | 'photo' | 'clock' | 'text';

interface Card {
  id: string;
  type: CardType;
  label: string;       // ひらがな等のキャプション（text型では本文）
  // 種別ごとの追加フィールド
  illustId?: string;   // type='illust' 時、プリセットのID
  photoPath?: string;  // type='photo' 時、ローカル画像パス
  clockTime?: { h: number; m: number };  // type='clock' 時
  createdAt: string;
}
```

### Scene（マイリスト）
```ts
interface Scene {
  id: string;
  name: string;             // 20文字以内
  cardIds: string[];        // 順序が意味を持つ
  isFavorite: boolean;      // ★お気に入り
  createdAt: string;
  updatedAt: string;
  lastUsedAt?: string;      // 最終実行日時（お気に入り以外の並び順判定に使う）
}
```

### UserProfile
```ts
interface UserProfile {
  childName: string | null;
  soundEnabled: boolean;
  plan: 'free' | 'monthly_480' | 'monthly_980';
  favoriteSceneIds: string[];  // Scene.isFavorite と二重管理でも、順序保持のためあると便利
}
```

## 10. スコープ外（v3.x 以降）

## 11. 非機能要件

- パフォーマンス：起動2秒、画面遷移300ms、タップ応答100ms
- アプリサイズ：100MB 以下（イラスト・写真サンプル込み）
- オフライン：コア動作はネット不要
- 対応OS：iOS 15+、Android 10+
- 言語：日本語のみ

## 12. アクセシビリティ
