# mitooshi LP 構成案

> **想定**: ターゲット = 保護者（一般 / 診断有無問わず） / CV = 事前登録・ウェイトリスト / ボリューム = 6セクション
> **トーン**: 共感パートは保護者の生々しい怒り・自己嫌悪を拾う / 解決パート以降は温かく前向き。絵文字は使わない
> **禁止**: 「治る」「改善」「克服」「普通の子と同じ」などの表現、子どもの顔写真、絵文字全般

---

## 全体設計の考え方

### このLPの本質
診断済みの保護者だけでなく「うちの子、なんだか他の子と違うかも…」と感じ始めたグレーゾーン層を含めて受け止めるLP。**診断という壁の手前で離脱させない**ことが最重要。専門用語を最小化し、日常の困りごとから入る。

### CVの現実
事前登録なので、ハードルは高くないがインセンティブが弱い。「リリース時に通知が届く」だけではメールアドレスを渡す理由にならないので、**事前登録特典**（先行アクセス権・初月無料・限定テンプレート等）を設計に組み込む。

### 読了の流れ
共感（自分のこと）→ 解決（何ができる）→ 信頼（誰が作っている / 安全か）→ 行動（登録）の順序。途中で重い説明を入れず、スクロールが止まらないように構成する。

## セクション1: HERO

### 目的
3秒で「自分のためのアプリだ」と確信させ、登録動線へ。

### 構成要素
- **キャッチコピー**（メイン）: 「もう何回言わせるの！」と叫ばなくていい朝へ。
- **サブコピー**: テンプレートを選ぶだけで、子どもが自分で次の行動を見つけられる。声かけに頼らない、新しい毎日の進めかた。
- **ビジュアル**: 実行画面（子どもがタップしている瞬間）のスクリーンショット、または手描きイラスト。プライバシー配慮で実写は使わない
- **CTAボタン**: 「事前登録する（無料）」 + 補足「リリース時にお知らせします」
- **信頼バッジ**: HCD-Net認定専門家 監修 / 療育現場の声を反映 など（事実ベースで）

### コピーの方向性メモ
「見通し」「特性」「療育」のような専門語をHEROでは避ける。最初は「つぎ、なに？」のような子どもの実際の言葉で入る方が、未診断層にも届きやすい。

## セクション2: 共感パート（こんな毎日、ありませんか？）

### 目的
保護者の「日常の怒り・自己嫌悪・諦め」を生々しく言語化し、「これ、私のことだ」と痛みごと受け止める。きれいごとにせず、朝の怒鳴り声や引き出しの奥で眠るグッズまで描く。

### 構成要素
- **セクション見出し**: こんな毎日、ありませんか？
- **共感ポイント**（3つ、カード形式・絵文字なし / 番号タグのみ）:
  1. **01** 「もう何回言わせるの！」朝から怒鳴ってしまった自分に、出勤途中の電車でひとり落ち込む。
  2. **02** 時計の針がすすむほど、声が大きくなる。「早くして」「あと5分」気づけば、命令と急かしの連続。
  3. **03** 絵カードもタイマーも、続かなかった。試したものは全部、引き出しの奥で眠っている。
- **クロージング**:
  > 叱りたくて叱っているわけじゃない。本当は、もっと優しくしたい。
  > それは、あなたの愛情が足りないからではありません。
  > お子さんが**「次に何をすればいいか」**を、目で見て確かめられないからです。

### 注意
ここでは「ASD」「ADHD」「発達障害」という単語を**まだ出さない**。診断のない層も自分ごと化できるようにする。怒り・自己嫌悪を否定せず一度受け止めてから、「あなたのせいではない」へ着地する構造が要。

## セクション3: mitooshiとは（ソリューション提示）

### 目的
何ができるアプリなのかを、機能ではなく**体験**で伝える。

### 構成要素
- **セクション見出し**: 「つぎ」が見えると、子どもは自分で動ける
- **3ステップで体験を説明**:
  1. **えらぶ** — 「あさのしたく」「おでかけ」などテンプレートをタップ
  2. **ととのえる** — ステップの順番と時間を指でならべ替え（30秒で完成）
  3. **わたす** — お子さんに画面を渡すだけ。子ども自身がカードをめくって進めます
- **強調コピー**: 30秒で見通しボードが完成。あとは、子どもが主役。
- **ビジュアル**: 画面遷移のGIF or 連続スクショ。保護者画面（編集）→ 子ども画面（実行）の流れを示す

### キーメッセージ
「親が頑張る」のではなく「子どもが自分で動けるようになる」という主語の転換を、ここで明確にする。

## セクション4: なぜ続くのか（mitooshiの特徴）

### 目的
「他のアプリや絵カードと何が違うか」を伝え、過去の挫折経験を払拭する。

### 構成要素
- **セクション見出し**: 続かなかった理由を、ぜんぶなくしました
- **特徴4つ**（左にBefore、右にmitooshiの構造）:
  1. **30秒で完成** — テンプレ選択 → そのまま使える。準備の手間ゼロ
  2. **外出先で組み換え自由** — 急な予定変更にも、その場で対応
  3. **子どもが自分で操作** — タップとスワイプだけ。文字が読めなくてもOK
  4. **オフラインでも動く** — 電波がない場所でも安心
- **補足コピー**: アナログの絵カードでうまくいかなかった方こそ、試してみてください

### 注意
競合（LITALICOやることカード等）の名前は出さない。あくまで「過去の挫折経験」全般を払拭する書き方で。

## セクション5: 利用シーン

### 目的
具体的な日常の場面を見せることで、自分の生活に置き換えてイメージしてもらう。

### 構成要素
- **セクション見出し**: 一日のいろんな場面で
- **シーンカード**（3つ、横並び）:
  1. **MORNING / あさ** — 「おきる → きがえ → ごはん → はみがき → いってきます」が、声かけなしで進む
  2. **OUTDOOR / おでかけ先** — お店で急に「もうかえる！」となっても、その場で予定を組み替え
  3. **NIGHT / ねるまえ** — 「おふろ → パジャマ → えほん → おやすみ」のリズムが整う
- **各カードに画面イメージ**を1枚ずつ

### コピーのトーン
ここは具体的な情景描写。「子どもが自分で次のカードに手を伸ばす」「ぐずぐずしていた朝が、リズムに乗って進む」といった、保護者が思わず想像してしまうディテールを盛り込む。

## セクション6: 安心ポイント + 事前登録CTA

### 目的
最後の不安（プライバシー・課金・継続性）を払拭し、登録に踏み切ってもらう。

### 構成要素

#### 6-A. 安心ポイント（3つ並列）
- **PRIVACY / プライバシー** — お子さんの情報は最小限。写真も名前も登録不要
- **FREE / ずっと無料で使える機能あり** — 基本のテンプレートは無料で。有料は必要な方だけ
- **EXPERT / 専門家の知見を反映** — HCD-Net認定の人間中心設計専門家が監修

#### 6-B. CTAブロック
- **見出し**: もうすぐリリース。まずは事前登録から
- **特典**:
  - リリース時に最速でお知らせ
  - 先行アクセス権（リリース前の体験）
  - 事前登録者限定テンプレート
- **フォーム**: メールアドレス1項目のみ
- **ボタン**: 「事前登録する（無料・1分で完了）」
- **マイクロコピー**: 配信停止はいつでもできます / メールアドレス以外の情報は取得しません

### 注意
ASD/ADHDという言葉は、ここまでで一度も出さなくてもLP全体は成立する。出すなら6-Aの専門家監修コメントの中で「軽度ASD/ADHDのお子さまに合わせた設計」と一度だけ触れる程度が適切。診断有無に関わらず迎え入れる姿勢を最後まで保つ。

## 制作上のメモ

### コピーライティング原則
- 一文を短く。スマホで読まれる前提
- 「お子さま」より「お子さん」のほうがやわらかい
- 命令形・指示形を避ける（〜してください → 〜できます）
- 数字は積極的に使う（30秒、3ステップ、4つの特徴）

### 計測すべき指標
- スクロール深度（各セクションの到達率）
- HEROのCTAクリック率 vs セクション6のCTAクリック率
- フォーム表示 → 完了の離脱率
- 流入元別CV率（ASO/SNS/口コミ）
