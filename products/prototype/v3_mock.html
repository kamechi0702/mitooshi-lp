フロー（F2：新規作成）

TOP → 下部「＋新規作成」 → S2 タイトル入力 → S5（空のリスト） → ＋ → S3 種別選択
→ S4a/b/c/d カード作成 → S4確認 → S5 にカード追加（繰り返し）→「リストを保存する」 → TOP に新リスト

フロー（F1：実行）

TOP → リストをタップ → S6 実行画面 → 上からタップで消化 → 最後を消すと自動で → S7 完了 → ホームへ戻る → TOP

フロー（F3：編集）

TOP → リスト行を長押し → S5 リスト編集画面 → 並び替え／削除／鉛筆で個別編集（→ S4に戻る）／＋で追加 →「リストを保存する」 → TOP
