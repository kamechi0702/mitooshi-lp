# mitooshi — プロトタイプ

## このフォルダの役割

ブラウザで直接開いて触感検証できる HTML/JS インタラクティブモック。体験仕様（2タップ原則・縦型カード積層・上スワイプ・実行中編集なし等）の早期検証を目的とする。

## ファイル

```
products/prototype/
├── index.html          v3 インタラクティブプロトタイプ（PRD v3.0 準拠）
├── v2_index.html       v2 プロトタイプのアーカイブ（縦型積層スワイプ体験）
└── v3_mock.html        v3 静的UIモック（10画面を1画面で一望する比較用）
```

- **v3（現行）**: 単一ファイル。下部タブバー・リスト型TOP・4種カード作成・タップ消化実行
- **v2（アーカイブ）**: 縦型カード積層・上スワイプめくり体験の旧モック
- **v3_mock**: 各画面を並べた静的UIモック（デザイン比較用）

## 起動方法

```bash
# ブラウザで直接開く
open products/prototype/index.html

# またはローカルサーバー経由
cd products/prototype && python3 -m http.server 8000
# → http://localhost:8000 で開く
```

## カードイラストの参照先

`index.html` 内の `ILLUST_BASE` 定数：

```js
const ILLUST_BASE = '../../shared/illust/mitooshi/';
```

`shared/illust/mitooshi/` に配置されている mitooshi トーン版の PNG を参照する。v3 では `ILLUST_LIBRARY` 辞書で各カードを `{id, label, file, category}` にマッピングし、S4a のカテゴリタブ（幼児一日／家族一日／学校一日／おでかけ／おかいもの）でフィルタ表示する。

## 検証観点（v3）

- **2タップ原則**：TOPからリスト実行まで最大2タップ（行タップ→最初のタスク消化）で到達できるか
- **下部タブナビゲーション**：TOP／新規作成（FAB）／マイページの切替が直感的か
- **リスト型実行画面**：縦並び＋チェック円＋タップで fwap 消化の手応え
- **4種カード作成の導線**：イラスト／画像／時計／文字の4パスで同等に作れるか
- **長押し編集**：TOP 行を長押しで S5 に入る体験は発見しやすいか
- **タイマー不在の体験**：時間を見せなくても不安にならないか
- **完了演出（S7）**：紙吹雪＋達成アイコン＋ホーム戻りボタンで達成感が出るか
- **保存→TOP反映**：新規リスト作成→TOP の通常セクションに出現する流れが分かるか
