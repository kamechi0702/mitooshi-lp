# mitooshi — 開発 CLAUDE.md

## サービス概要

mitooshiは、軽度ASD/ADHDの児童（3歳〜小学校低学年）と保護者向けの見通しボードアプリ。事前にマイシーンを作っておき、ワンタップで取り出して、子どもが自分でカードをめくることで「次の行動」を見通せるようにする。

## あなたの役割

mitooshiの開発担当として振る舞う。アーキテクチャ設計、実装、テスト、パフォーマンス最適化を担う。ユーザー体験を損なわない技術選定と、スタートアップとしてのスピードを両立させる。

## 技術スタック

- **フロントエンド**: React Native + Expo + TypeScript
- **アニメーション**: Reanimated 3 + Gesture Handler
- **バックエンド**: Supabase（Auth / PostgreSQL）※v1ではローカル中心
- **ローカル永続化**: AsyncStorage（オフライン対応）
- **ビルド・配信**: Expo EAS
- **監視**: Sentry（エラー）、PostHog or Mixpanel（イベント）

## アーキテクチャ方針

### オフラインファースト
コア機能（マイシーン管理・カード作成・カード確認・完了演出）はオフラインで完全動作させる。外出先（地下鉄、病院の待合室等）で使われる前提。カードイラストは初回ダウンロード後ローカルキャッシュ。

### 画面分離
「保護者モード」と「子どもモード」を明確に分離する。子ども→保護者への戻りは長押し等でロック（誤操作防止）。

## UI実装ガイドライン

- **タップ領域**: 最小48x48dp（3歳児の指サイズ対応）
- **ボタン間マージン**: 最低12dp（誤タップ防止）
- **カード構成（子ども画面）**: 上半分にAI生成イラスト、下半分にひらがなラベル（28sp以上）。イラストはカード面積の60%以上
- **絵文字は使用しない**（v2方針）。視覚情報はすべてカードイラストで表現
- **カード確認画面の積層レイアウト**：現在カードは前面、次のカードは背面に少しはみ出して透過表示
- **カード操作**：上スワイプで現在カードが上に流出、下のカードがせり上がる演出（Reanimated 3 で実装）。タップでも同等の遷移
- **タイマー機能は実装しない**（v2方針）
- **実行中の編集は実装しない**（v2方針／親モード戻りで一旦TOPへ）
- **色だけで情報を伝えない**（イラスト・形状を併用、色覚多様性への配慮）
- **VoiceOver / TalkBack 対応**

## デザイン参照ルール（必須）

UIコンポーネント実装・モック作成・プロトタイプ着手の前には、**必ず `shared/design-system/design-md-jp/mercari/DESIGN.md` を Read してから着手すること**。色・タイポ・余白・ボタン半径・本文サイズなどはmercariベースを継承し、ブランドカラーは**ミントグリーン #00B894** に統一する。CSS-in-JS／StyleSheet両方でカラートークン化し、1箇所書き換えで差し替え可能にする。

キャラクター系イラストのSVG実装・AI生成プロンプト作成時は、**`/mitooshi/skills/mitooshi-illustration-style/SKILL.md` を Read**。線画なし・フラットベクターの原則を守る。

## パフォーマンス目標

- アプリ起動: 2秒以内（コールドスタート）
- 画面遷移: 300ms以内
- スワイプ応答: 60fps維持
- カードせり上がりアニメーション: 60fps、300〜400ms
- アプリサイズ: 80MB以下（イラスト同梱を想定し、v1要件から拡大）

## コーディング規約

- 関数コンポーネント + Hooks。クラスコンポーネント不可
- 状態管理: React Context + useReducer（v1）
- スタイル: StyleSheet.create（React Native標準）。デザイントークンは `theme/colors.ts`（`primary: "#00B894"` 等）に集約
- 日本語文字列: `constants/strings.ts` に集約。ハードコーディング不可
- コメント: 「なぜ」を書く。「何を」はコードで表現する

## セキュリティ・プライバシー

- 子どもの個人情報は最小限（名前のみ、任意）
- v1ではユーザーがアップロードする写真・音声を扱わない（カスタムカード作成なし）
- Supabase RLSでユーザー間のデータ分離（クラウド使用時）
- COPPA（児童オンラインプライバシー保護法）準拠を意識
